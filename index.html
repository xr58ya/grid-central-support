Common problems

"Windows protected your PC" when installing

The beta isn't code-signed yet. Click More info, then Run anyway. If your antivirus blocks GridCentral.exe, allow it.

My beta code isn't accepted

Check it's typed exactly as sent (GC-XXXX-XXXX-XXXX). A brand-new code can take a little while to switch on. If it still fails, email us. Never post your code publicly.

"Companion not running" or "IRACING NOT CONNECTED"

Start the companion (Settings → Connections → ▶ Start companion) and leave its small window open.

"Waiting for iRacing"

The companion is fine. Load into a session and get in the car: iRacing's garage menus don't send live data.

No spoken calls

Click anywhere in Grid Central once (the browser blocks sound until you do), then check the switches in Settings → Voice & radio.

Talkback doesn't hear me

In Settings → Voice & radio → Talkback, check the microphone and button, and that the status says READY. The first time, it downloads a speech model (about 40 MB). Hold the button a moment before speaking.

The in-game overlay doesn't show over iRacing

Set iRacing to windowed or borderless, not full screen. Ctrl+Alt+O shows and hides the overlay.

OBS keeps showing a different overlay design

The Grid Central Overlay source in OBS keeps its design (marked · OBS in the designer's list). Open the design you want and press Add to OBS again.

I hear the commentary in my headset

In OBS, on the Grid Central Browser source, tick Control audio via OBS and set Audio Monitoring to Monitor Off (Edit → Advanced Audio Properties).

My paint doesn't show in iRacing

Install needs the companion running and your iRacing ID in the paint shop's Setup. If the Trading Paints Downloader has "Update my own paints" ticked, it replaces your paint: untick it. Grid Central's install card says which problem it found.

The phone pit wall won't connect

Use the same Wi-Fi as the PC (not mobile data or a guest network), set the Windows network to Private, and scan the QR code again if your PC's address changed.

A new feature is missing after an update

Press Ctrl+F5. If it's still missing, close every Grid Central window and open it again.

The companion closed or overlays stopped
  1. Open the Start menu, find Grid Central, right-click it and choose Open file location.
  2. Report the problem and attach companion.log (and companion-previous.log, if it's there), with the track, car and what you were doing.

Contact us

When reporting a problem, include your version (bottom right of the app, for example V 0.5.9.2 · BETA), the track, the car and what you were doing.
