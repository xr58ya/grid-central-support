# Grid Central Support

This is the place to report problems, suggest features and get help with Grid Central.

- **Something broken?** [Report a bug](../../issues/new?template=bug_report.yml)
- **Have an idea?** [Request a feature](../../issues/new?template=feature_request.yml)
- **Stuck setting something up?** [Ask for setup help](../../issues/new?template=setup_help.yml)

Before opening a new issue, please [search the existing ones](../../issues?q=is%3Aissue). If someone has already reported the same thing, add a 👍 and any extra detail as a comment.

Prefer email, or need to share something privately (such as an account or beta code)? Write to **support.gridcentral@gmail.com**.
