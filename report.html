Report a problem

Two ways to send it. Post on GitHub opens our public tracker with your answers filled in: you pick from GitHub's lists again and press Create (a free GitHub account is needed, and anyone can read it). Send by email opens your email app instead, so only we see it. Before posting, please search existing reports.

* marks the answers we need.

GitHub is public: never post beta codes, email addresses or full logs there, send those by email instead. Never include passwords, payment details or your iRacing login anywhere. Questions? Email support.gridcentral@gmail.com.
